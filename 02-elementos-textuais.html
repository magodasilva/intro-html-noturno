Aprendendo sobre elementos textuais

O que são os elementos textuais?

Os elementos textuais servem para destacar, enfatizar ou dar um significado a partes específicas do conteúdo.

Elemento strong

É muito importante aprender a estrutura do HTML.

A tag strong(forte) é utilizada para indicar que determinado trecho possui forte importância.

Elemento b

Aprenda HTML , CSS e JavaScript para criar páginas web.

A tag b(bold) também costuma deixar o texto em negrito, mas sua finalidade é criar apenas um estilo/destaque visual.

Elemento em

Você realmente precisa estudar.

O elemento em comunica que aquele trecho deve receber uma determinada ênfase dentro da frase.

Elemento i

O termo software é utilizado com frequência na área de tecnologia.

O elemento i possui a mesma formatação visual que o elemento em, porém, não possui valor semântico. É apenas estilo visual.
